# Keyboard Shortcuts

## General

| Action | Shortcut |
|--------|----------|
| Open Database | Ctrl+O |
| New Database | Ctrl+N |
| Save | Ctrl+S |
| Save Database As | Ctrl+Shift+S |
| Print | Ctrl+P |

## Text Formatting

| Action | Shortcut |
|--------|----------|
| Bold | Ctrl+B |
| Italic | Ctrl+I |
| Underline | Ctrl+U |

## Undo / Redo

| Action | Shortcut |
|--------|----------|
| Undo | Ctrl+Z |
| Redo | Ctrl+Y |

## Pasting

| Action | Shortcut |
|--------|----------|
| Paste (current default mode) | Ctrl+V |
| Paste as plain text | Ctrl+Shift+V |

## Lists

| Action | Shortcut |
|--------|----------|
| Indent list item | Tab  or  Ctrl+] |
| Outdent list item | Shift+Tab  or  Ctrl+[ |
| Move item up | Ctrl+Up |
| Move item down | Ctrl+Down |

## Tables

| Action | Shortcut |
|--------|----------|
| Move to next cell | Tab |
| Move to previous cell | Shift+Tab |
| Insert row at end of table | Tab (from last cell) |
| Table context menu | Right-click |

## Tree Navigation

| Action | Shortcut |
|--------|----------|
| Move selected item up | Ctrl+Up |
| Move selected item down | Ctrl+Down |
